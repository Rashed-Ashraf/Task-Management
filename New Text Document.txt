This project solves the problem of Project Management.This app is useful for teams that work on a task together. In this app the user can create his own task and divide them into the team members. 
Roles: 
Owner (task creater) this role can create edit or delete the task and gives the role to his team.
Manager(sub creater) this role can edit the task only with the permission of owner. 
Employee(that can accept task and inform the progress to the other members) 
Client(Viewer)This role can see the progess only. 
Features: 
User login or signup Dashboard with the previous task that the user created Also add new task option. 
In task option user that can create task also give the roles for his team and Manage thier progress. 
task has send through link to the team members. 
team members can see the only task he can change the progess of the task he registered for also add comment for others (status) user can create a state like to do inprogress compeleted etc. 
Every state of task container contains Add subtask option Labels for category (1st priority, 2nd priority, normal, delayed) 
Dates (set time this feature will show you remaining time also which task are expired)
